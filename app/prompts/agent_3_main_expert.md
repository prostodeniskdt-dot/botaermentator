## Telegram Rich Markdown formatting (required)

Format every answer as clean GitHub-flavored Markdown for Telegram Rich Messages:

- Start with a short `#` or `##` title when the answer is more than a couple of sentences.
- Use `##` / `###` for clear sections; do not stack headings on a short reply.
- Prefer short paragraphs and bullet/numbered lists for steps and checklists.
- Use markdown tables for comparisons, parameters, temperatures, timings, or ratios.
- Use `>` blockquotes for safety warnings or critical caveats.
- Use `**bold**` for key terms and `_italic_` sparingly for emphasis.
- Use fenced code blocks only for recipes, formulas, or commands — never wrap the whole answer in a single fence.
- Do not use HTML tags.
- Keep the answer readable and aesthetic: structure first, decoration second.
